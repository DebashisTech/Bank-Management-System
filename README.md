# 🏦 Bank Management System

A Java-based Bank Management System that simulates basic banking operations through a graphical user interface (GUI). The application allows users to securely access banking services, manage accounts, and perform financial transactions using Java Swing and MySQL.

## 📌 Project Overview

The Bank Management System is a desktop-based application developed using **Java, Java Swing, JDBC, and MySQL**. It provides essential banking functionalities such as account registration, user authentication, balance enquiry, cash deposit, cash withdrawal, fast cash, PIN management, and mini statements.

The project demonstrates practical implementation of Java programming, object-oriented programming (OOP), database connectivity, and event-driven GUI development.

## ✨ Key Features

- **User Registration:** Register new customers and create bank accounts.
- **User Authentication:** Login functionality with account credentials and PIN.
- **Balance Enquiry:** Check the current account balance.
- **Cash Deposit:** Deposit money into the account.
- **Cash Withdrawal:** Withdraw money from the account.
- **Fast Cash:** Withdraw predefined amounts quickly.
- **Mini Statement:** View recent account transactions.
- **PIN Change:** Update the account PIN.
- **Transaction Management:** Perform and manage banking transactions.
- **Database Connectivity:** Store and retrieve customer and transaction details using MySQL.

## ⚙️ Installation and Setup

Follow these steps to run the project locally.

### 1. Clone the Repository

```bash
git clone https://github.com/DebashisTech/Bank-Management-System.git
```

### 2. Open the Project

Open the cloned project in IntelliJ IDEA or NetBeans.

### 3. Configure MySQL Database

- Install and start MySQL Server.
- Create the required database.
- Configure your database connection details in the `Conn.java` file.
- Ensure the database tables match the application's SQL queries.

### 4. Configure JDBC Driver

Add the MySQL Connector/J library to the project's classpath.

### 5. Run the Application

Run the `Login.java` file to launch the application.
